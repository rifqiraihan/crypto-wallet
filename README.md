# Connect Wallet & Crypto Prices

This is a React application that allows users to connect their MetaMask wallet, view their Ethereum balance, and check real-time cryptocurrency prices using the CoinGecko API.

## Features
- Connect and disconnect MetaMask wallet
- Display Ethereum address and balance
- Fetch crypto prices from CoinGecko
- Responsive UI using Material-UI and TailwindCSS

## Technologies Used
- **React 18**
- **TypeScript**
- **Material-UI**
- **TailwindCSS**
- **Web3.js**
- **CoinGecko API**
- **pnpm** (package manager)

## Installation

1. Clone this repository:
   ```sh
   git clone https://github.com/yourusername/connect-wallet.git
   cd connect-wallet
   ```

2. Install dependencies using pnpm:
   ```sh
   pnpm install
   ```

3. Start the development server:
   ```sh
   pnpm dev
   ```

4. Open the application in your browser at `http://localhost:5173/` (Vite default port).

## Usage

- Click **"Connect Wallet"** to link your MetaMask account.
- Your wallet address and Ethereum balance will be displayed.
- Check the latest cryptocurrency prices in real-time.

## Environment Variables (Optional)

This project uses the CoinGecko API, which doesn't require an API key, but you can set up additional configuration if needed.
